An interactive data visualization for tracking and analyzing my personal Smiski figurine collection. The application contains interactive metrics and visualizations that make it easy to understand my collection progress, series distribution, and overall collection trends. The Smiski Collection Dashboard turns a personal collection into an interactive data analytics project.

Application: https://destinys-smiski-collection.streamlit.app/

Software: Python, Pandas, Streamlit
